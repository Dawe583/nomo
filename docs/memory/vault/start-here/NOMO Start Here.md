## 📌 Quick rules

1. Read this page and [[NOMO Memory Rules]] before adding or restructuring memory.
2. Record one topic per note. Link to source evidence and label uncertainty.
3. Update the existing canonical note instead of creating a duplicate.
4. Preserve history by superseding or archiving, never silently deleting it.
5. Add new notes to the relevant index and update the canvas only when the knowledge map materially changes.
6. Never put secrets, credentials, personal data, or raw conversation dumps in this vault.

## 🧠 Central node and 16 spheres

The global Graph view is deliberately lightweight: [[NOMO Start Here]] is the central NOMO brain and the 16 domain notes are its spokes. Each spoke routes to its domain's canonical notes and related areas. The full, detailed note network stays in the local area graph or the [[NOMO Knowledge Map.canvas]]. Generated source files remain excluded from this default overview so Obsidian stays responsive.
