# NOMO harness delegation

Keep the selected harness's native tools, subagents, teammates, and delegation
features available at their normal project-permitted level. Spawn subagents only
when the user explicitly asks. A session may use up to five active subagents;
follow any lower native runtime limit, and do not claim this skill enforces a
hard cap by itself. Route work through the active graph, preserve existing
worktrees and dirty files, and coordinate shared file writes through explicit
ownership. The primary agent integrates work and verifies evidence.

Independent graph nodes may proceed concurrently when source paths are disjoint
and no real dependency exists. Do not wait for another harness to finish
unrelated work. Hand off through the designated graph without granting multiple
writers to that graph file. Reuse the assigned worktree; do not use detached
runs to bypass graph ownership, approvals, or native limits.
