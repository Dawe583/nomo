Run the TUIFull terminal guide

From source to workspace

Two commands.
Your terminal.

Install Node.js 24 or newer and pnpm 10. Extract the source ZIP, open Terminal in the extracted folder, then run: 

pnpm install --frozen-lockfile
pnpm tui

On macOS, VOID.command in that folder also launches the TUI after dependencies are installed.

Connect a model provider before your first conversation. Existing OpenCode TokenRouter settings can be imported with /connect opencode:tokenrouter. Provider availability and usage limits still apply.

Start in the browser.

Open the web app if you want to try VOID before installing it.
