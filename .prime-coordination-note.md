## Test slot

Žádný můj `node --test` ani `npx tsc` neběží. Poslední běh doběhl před
posledním commitem. Můžete spouštět.

Když spouštím já, používám vždy jeden příkaz najednou, nikoli paralelně:

```
npx tsc -p packages/cli/tsconfig.json --noEmit
node --test --test-concurrency=1 packages/cli/src/tui/*.test.ts
```

Právě teď **žádný subagent neběží**. Dva selhali na rate limit (`impact.ts`,
`triage.ts`), takže ty soubory nebyly vytvořené. Zkusím je znovu.

## Co potřebujete udělat

Větev `docs/nomo-agent-identity-fleet-2026-10-08` má commity nad novým main.
Před sloučením:

```
git rebase origin/main
```

Možné konflikty, všechny ze stejného kořene — main si ponechal `void` jména:

| Oblast    | Co na main je                           | Co by v rebase selhalo     |
| --------- | --------------------------------------- | -------------------------- |
| balíčky   | `@void/*`                               | `@nomo/*` v `package.json` |
| nástroje  | `void_workspace_list/read/write/delete` | `nomo_workspace_*`         |
| env       | `VOID_*`                                | `NOMO_*`                   |
| dokumenty | část smazána, část editována            | add/add nebo modify/delete |

Dokumenty jsou zvlášť pravděpodobný zdroj: sloučení respektovalo smazání
těch, které main smazal, a při srážce s vašimi zbraněmi to bude konflikt.

**Pozor na merge past, který main už jednou projevil.** Při prvním sloučení
auto-merge nechal `server.ts` číst `env.VOID_*` z allowlistu, který deklaroval
`NOMO_*`. Kompilovalo se to a selhalo to až za běhu, ve 7 testech control-plane.
Pokud po rebase uvidíte `NOMO_*` nebo `nomo_` v `packages/cli` nebo
`apps/control-plane`, hledejte tu: deklarace a použití se musí shodovat, jinak
jde o kód, který se nikdy nespustí.

nemusí. Pokud narazíte na chybu, která žije mimo ten adresář, je to merge
artefakt a já ho opravím.
